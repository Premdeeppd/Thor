# SUP-1427: Order Lookup shows another customer's orders after a fast search

**Reported by:** Support team lead (Tier 2)
**Priority:** High. Agents have quoted the wrong order to customers on calls.
**Where:** Order Lookup (internal), Chrome on macOS

## What agents are seeing

When an agent types a customer's name quickly (for example `alice`), the table sometimes ends up full
of orders for other customers. It looks like the results of a shorter search, but the search box
still says `alice` and the line above the table says *for "alice"*. Clearing the box and typing
again usually fixes it. This happens several times a day, mostly at busy times.

## How we see it

Open Order Lookup and type `alice` at normal speed. Often the rows don't match the search.
Typing very slowly gives the right rows.

## Expected

- The table always shows results for exactly what is in the search box, however fast the agent types.
- If a search fails, agents still see an error message.
