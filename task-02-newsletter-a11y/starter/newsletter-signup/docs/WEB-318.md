# WEB-318: Newsletter sign-up page fails the accessibility release check

**Reported by:** Web platform lead
**Priority:** High. The page is due to go live on Friday and can't ship until it passes.
**Where:** Newsletter sign-up page (`index.html`), Brave on macOS

## What happened

Our release checklist (see the README) requires a Lighthouse Accessibility score of 100. The new sign-up page doesn't reach it.

A reader who uses VoiceOver also tried the beta and wrote in: "The email box is read out as just 'edit text', so I had to guess what to type."

## How to check

Open the page, then DevTools → Lighthouse → tick only Accessibility → Analyze page load.

## Expected

- Lighthouse Accessibility score of 100, with no failed audits.
- The email field has a label that screen readers read out, and the form works with the keyboard.
- The page keeps its current look, apart from any colour changes needed for contrast.
