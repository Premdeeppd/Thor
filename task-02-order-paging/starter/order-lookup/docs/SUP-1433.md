# SUP-1433: "Load more" shows the same order twice

**Reported by:** Support team lead (Tier 2)
**Priority:** High. Agents work the order list top to bottom and are handling some orders twice.
**Where:** Order Lookup (internal), Brave on macOS

## What agents are seeing

At busy times, paging through the order list with **Load more** sometimes shows the same order ID
twice: once at the bottom of one page and again at the top of the next. Agents are worried that
some orders are being missed as well.

## How we see it

Open Order Lookup with an empty search. When new orders come in, click **Load more**.
Duplicate order IDs appear near the page boundary.

## Expected

- Paging through the list never repeats or skips an order, even while new orders are arriving.

## Notes from triage

- Production receives new orders continuously. Locally, engineering can simulate arrivals with
  `POST /api/dev/simulate-orders?count=3` (see README).
- The search fix from SUP-1427 is already in this build.
